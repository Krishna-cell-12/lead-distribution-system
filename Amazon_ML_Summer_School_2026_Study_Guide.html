SECTION 1

📊 Probability

1.1 Basic Probability Rules

P(E) = Favorable outcomes / Total outcomes
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
P(A') = 1 − P(A) [Complement Rule]

Mutually Exclusive Events

A ∩ B = ∅ → P(A ∪ B) = P(A) + P(B)

1.2 Conditional Probability

P(A|B) = P(A ∩ B) / P(B), where P(B) ≠ 0
P(A ∩ B) = P(A|B) · P(B) = P(B|A) · P(A) [Multiplication Rule]

Independence

Events A, B are independent iff: P(A ∩ B) = P(A) · P(B)

Equivalently: P(A|B) = P(A)

1.3 ⭐ Bayes' Theorem (MOST TESTED!)

🌟 #1 Most Asked Topic in Amazon ML Summer School MCQs! Practice at least 10 Bayes' problems before the test.
P(A|B) = P(B|A) · P(A) / P(B)

Extended: P(Aᵢ|B) = P(B|Aᵢ) · P(Aᵢ) / Σⱼ P(B|Aⱼ) · P(Aⱼ)

Terminology

TermSymbolMeaning
PriorP(A)Initial belief before evidence
LikelihoodP(B|A)Probability of evidence given hypothesis
PosteriorP(A|B)Updated belief after evidence
EvidenceP(B)Total probability of evidence

Worked Example

Q: Factory has 2 machines. Machine A: 60% of items, 2% defect. Machine B: 40%, 5% defect. If item is defective, probability it came from A?

P(A) = 0.6, P(B) = 0.4, P(D|A) = 0.02, P(D|B) = 0.05
P(D) = 0.02×0.6 + 0.05×0.4 = 0.012 + 0.02 = 0.032
P(A|D) = (0.02 × 0.6) / 0.032 = 0.012 / 0.032 = 0.375 = 37.5%

1.4 Expected Value & Variance

E[X] = Σ x · P(X=x) [discrete]
Var(X) = E[X²] − (E[X])²

Properties:
E[aX + b] = a·E[X] + b
Var(aX + b) = a²·Var(X) ← Adding constant does NOT change variance!
E[X + Y] = E[X] + E[Y] (always)
E[XY] = E[X]·E[Y] (only if independent)

Covariance & Correlation

Cov(X,Y) = E[XY] − E[X]·E[Y]
ρ(X,Y) = Cov(X,Y) / (σₓ · σᵧ), −1 ≤ ρ ≤ 1
⚠️ Trap Question: Cov(X,Y) = 0 does NOT mean X and Y are independent! It only means no LINEAR relationship. They could have a non-linear relationship.

Skewness

  • Right-skewed (positive): Mean > Median > Mode, long tail on right
  • Left-skewed (negative): Mean < Median < Mode, long tail on left
  • Symmetric: Mean ≈ Median ≈ Mode

2.2 Hypothesis Testing

💡 Memory Trick: Type I = False Positive (convicting an innocent). Type II = False Negative (letting a guilty person go).
p-value < α → Reject H₀ | p-value ≥ α → Fail to reject H₀

CI = x̄ ± z(α/2) · σ/√n
90% CI: z = 1.645 | 95% CI: z = 1.96 | 99% CI: z = 2.576

Central Limit Theorem

For n ≥ 30, the distribution of sample means approaches Normal distribution, regardless of population distribution.

X̄ ~ N(μ, σ²/n)
SECTION 3

🔢 Linear Algebra

3.1 Vectors

Dot Product: a⃗ · b⃗ = Σ aᵢbᵢ = |a⃗||b⃗|cos θ
Magnitude: |a⃗| = √(Σ aᵢ²)
Unit Vector: â = a⃗ / |a⃗|

L1 Norm (Manhattan): ‖a⃗‖₁ = Σ|aᵢ|
L2 Norm (Euclidean): ‖a⃗‖₂ = √(Σ aᵢ²)
📌 Key Fact: Orthogonal vectors have dot product = 0. This is VERY frequently tested!

3.2 Matrix Operations & Types

TypeProperty
Identity (I)Diagonal = 1, rest = 0; AI = IA = A
SymmetricA = Aᵀ
OrthogonalAᵀA = AAᵀ = I; so A⁻¹ = Aᵀ
Positive DefiniteAll eigenvalues > 0; xᵀAx > 0 for all x ≠ 0
Singulardet(A) = 0; NOT invertible
(AB)ᵀ = BᵀAᵀ
(AB)⁻¹ = B⁻¹A⁻¹
Matrix multiply: (m×n)(n×p) = (m×p)
AB ≠ BA in general (NOT commutative!)

3.3 Determinants

2×2: det|a b; c d| = ad − bc

Properties:
det(AB) = det(A) · det(B)
det(Aᵀ) = det(A)
det(cA) = cⁿ · det(A) for n×n matrix
det(A⁻¹) = 1/det(A)
det(A) = 0 → matrix is SINGULAR (not invertible)
Swapping two rows → changes sign of determinant

2×2 Inverse

[a b; c d]⁻¹ = (1/(ad−bc)) · [d −b; −c a]

3.4 ⭐ Eigenvalues & Eigenvectors (FREQUENTLY ASKED!)

Av⃗ = λv⃗ where λ = eigenvalue, v⃗ = eigenvector

To find eigenvalues: det(A − λI) = 0 [Characteristic Equation]
🌟 Must-Know Properties:
PropertyFormula/Fact
Sum of eigenvalues= trace(A) = Σ aᵢᵢ
Product of eigenvalues= det(A)
Symmetric matrixAll eigenvalues are REAL
Positive definiteAll eigenvalues > 0
Diagonal matrixEigenvalues = diagonal entries
Eigenvalues of A⁻¹= 1/λ
Eigenvalues of Aᵏ= λᵏ

Worked Example

Find eigenvalues of A = [3 1; 1 3]

det(A − λI) = (3−λ)² − 1 = λ² − 6λ + 8 = (λ−4)(λ−2) = 0
Eigenvalues: λ₁ = 4, λ₂ = 2
Check: trace = 6 = 4+2 ✅ | det = 8 = 4×2 ✅

3.5 Rank & SVD

  • Rank = number of linearly independent rows/columns
  • Full rank: rank = min(m, n)
  • rank(A) = rank(Aᵀ)

SVD: A = UΣVᵀ

  • U: left singular vectors (orthogonal)
  • Σ: diagonal matrix of singular values
  • V: right singular vectors (orthogonal)
  • Used extensively in PCA and dimensionality reduction

4.6 Evaluation Metrics

Precision = TP / (TP+FP) → "Of predicted +, how many correct?"

4.8 Feature Scaling & Cross-Validation

Standardization: z = (x − μ) / σ → mean=0, std=1
Min-Max: x' = (x − x_min) / (x_max − x_min) → range [0,1]
💡 Which algorithms NEED scaling?
✅ Need: KNN, SVM, K-Means, Neural Networks, Linear/Logistic Regression (with GD)
❌ Don't need: Decision Trees, Random Forest, Gradient Boosting

K-Fold Cross-Validation

Split data into K folds → train on K−1, test on 1 → repeat K times → average. Common K: 5 or 10. Use Stratified K-Fold for imbalanced data.

Symmetric eigenvalues?Always REAL

CLT says?Sample means → Normal as n→∞
